## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/bicakciberk/bicakciberk.git
```

Open the project folder:

```bash
cd bicakciberk
```

Then simply open **index.html** in your browser or run it using the **Live Server** extension in VS Code.
